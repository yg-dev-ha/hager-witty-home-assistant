# Hager Witty Start for Home Assistant — v0.1.1

Reliability release for unstable Hager Cloud responses.

- Changes the default polling interval from 10 seconds to 30 seconds to reduce pressure on the Hager Cloud API.
- Retries one idempotent status GET after a transient network failure or HTTP 500/502/503/504 response, with a short 3-second backoff.
- Start/stop POST commands are deliberately **not** retried, avoiding duplicate charging commands when the cloud response is ambiguous.
- Keeps the existing OAuth refresh/retry behavior for 401/403 responses.
- Adds offline regression coverage for transient HTTP 500 and connection failures.

Existing installations that previously saved a custom 10-second scan interval keep that option until changed in Home Assistant. For installations affected by Hager Cloud instability, 30 seconds is recommended.

Validation covers offline regression tests plus HACS and Hassfest. Hardware behavior still depends on the Hager cloud and the vehicle. Independent community integration, not endorsed by Hager.
