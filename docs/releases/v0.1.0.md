# Hager Witty Start for Home Assistant — v0.1.0

Initial public release: Hager Cloud status, charging-session sensors and one Start/Stop switch, with HACS installation and English/French setup.

Includes OAuth PKCE authentication, automatic token renewal, unknown-state handling, redacted diagnostics and local light/dark branding. Requires Home Assistant 2026.10.0+ and a cloud-connected Witty Start already working in the Hager Witty app.

**Installation:** add this repository to HACS as an Integration, install and restart HA. For manual installation, extract the attached ZIP into the HA configuration directory. Keep an existing configuration entry when migrating from a manual installation.

This release does not adjust charging current or phases, provide local/OCPP access or automate solar surplus. Multi-charger accounts and other models are not validated. See README.md / README.fr.md for authentication, scope and troubleshooting.

Validation covers offline regression tests plus HACS and Hassfest. Hardware behavior still depends on the Hager cloud and the vehicle. Independent community integration, not endorsed by Hager.
